FUNCIÓN terremotos_anteriores (terremotos, fecha_hora)
    anteriores <- lista vacía
    para cada terremoto en terremotos hacer
        fecha_terremoto <- terremoto.fecha + " " + terremoto.fecha_hora
        
        Si fecha_terremoto < fecha_hora entonces
            añadir terremoto a anteriores
        Fin Si
    Fin para

    Devolver anteriores
Fin FUNCIÓN

¿Qué hace?
1. Crea una lista vacía para guardar los terremotos anteriores
2. Recorre todos los terremotos
3. Obtiene la fecha y hora de cada terremoto
4. Si es anterior a la fecha y hora
5. Si lo es se añade a la lista
6. Devuelve la lista

¿qué hace?
1. Crea lista vacía
2. Recorre todos los terremotos
3. Comprueba los que son posterior a la fecha
